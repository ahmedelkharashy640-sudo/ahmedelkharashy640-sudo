### 👨‍💻 About Me
I am a Computer Science student at Damanhour University, combining a strong foundation in competitive programming with hands-on experience in frontend development and software QA testing. My approach to software is built on logic and clean architecture, focusing not just on writing code that works, but on building reliable, high-quality systems.
With a deep interest in algorithms and number theory, I regularly practice problem-solving using C++ and Java. This analytical training led me to participate in the ECPC (Egyptian Collegiate Programming Contest), which has sharpened my ability to optimize code and debug complex logical issues efficiently. 
On the development side—and as an HR at ICPC Damanhour—I work as a Frontend Developer, currently advancing my skills through extensive, practical training at Semicode. I build clean front-end layouts using HTML, CSS, JavaScript, SASS, Bootstrap, and TypeScript, while leveraging my core strengths in Java and C++ for backend logic, alongside a working knowledge of Python. 
What sets me apart is my comprehensive understanding of the Software Testing Life Cycle (STLC). I don't just build features; I ensure their reliability through manual, API, database, and automated testing using tools like Selenium WebDriver, TestNG, and MySQL. This dual perspective allows me to bridge the gap between development and quality assurance, delivering software that is stable, scalable, and thoroughly tested.
Feel free to reach out if you want to connect, collaborate on tech projects, or discuss software engineering!
